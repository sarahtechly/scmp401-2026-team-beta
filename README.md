# SCMP 401 – Team Beta – Secure Web-Based Banking System

Course project for **SCMP 401: Software Engineering Studio** (Dr. Bestoon Hussien, Department of Computer Engineering).

This repository holds the Milestone 1 deliverables: the Software Requirements Specification (SRS), the UML use case model and the requirements traceability matrix.

## Repository structure

| Folder | Contents |
|---|---|
| `docs/` | SRS (`SRS.md`) and UML use case diagram |
| `src/` | Application code (starts in Milestone 2) |
| `tests/` | Automated JUnit test suites (start in Milestone 2) |

## Workflow

- `main` is protected and holds reviewed, release-ready work only.
- `develop` collects finished work from feature branches.
- Every change is made on a `feature/*` branch and merged by pull request.
- Every pull request needs one approving review from the ScrumMaster or the System Architect.
